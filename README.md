# 📁 File Manager API

A minimalist Node.js/Express service for uploading and storing files such as images. 
---

## ✨ Key Features
- *Multi-file (images) uploads* 
- *MongoDB storage* of filename, path, size & MIME type
- *CRUD endpoints* for file metadata
- *.env-driven config* for easy deployment

---

## 🔧 Tech Stack
- *Node.js 18+*
- *Express 5*
- *Multer* for multipart parsing
- *Mongoose* for ODM
- *dotenv* for env management

---

## 🚀 Quick Start

```bash
# 1. Clone & install
git clone https://github.com/<your-handle>/file-manager.git
cd file-manager
npm install

# 2. Environment variables
cp .env.filemanager        

# 3. Run
npm run dev                
```  

## 📁 Project structure

├─ controllers/     # Express controllers, file.js
├─ models/          
├─ routes/          # Express routes, file.js
├─ middleware/      # Multer config
└─ server.js
